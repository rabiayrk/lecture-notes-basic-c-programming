# Lecture notes: basic C programming

Short C examples for beginners, one topic per file. Most files have comments that explain the code. Files marked `mini_example` are small, complete programs such as a basic banking menu.

Topics: data types and conversions, arithmetic operators, `if`/`else`, `switch`, loops (`for`, `while`, `do while`, nested), `break` and `continue`, arrays and matrices, character arrays, recursion.

## Run an example

```bash
gcc hello_world.c -o hello_world
./hello_world
```

Written in 2020.
